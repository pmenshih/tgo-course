# Тесты лабораторных

Тесты читают артефакты из `labNN/artifacts/` (очный трек) или `ptNN/artifacts/` (заочное отделение) и пересчитывают из них все, что можно пересчитать. Код работы они не запускают и не импортируют: запуск делает CI, локально его делаете вы.

```
python lab02/run.py --fast && pytest tests/test_lab02.py
```

Пока `labNN/run.py` содержит `NotImplementedError`, модуль тестов этой работы пропускается.

В CI тесты всегда берутся из репозитория курса, а не из вашей копии, поэтому правки в `tests/` на проверку не влияют. Если тест кажется неверным, пишите преподавателю.

## Пороги

`data/lab02/thresholds.json`: значения из эталонного прогона `run.py --fast` (артефакты `search.json` и `attention_map.json`, прогон 11 октября 2026 года) минус 0.1; порог recall у e5 опущен до 0.75, то есть 9 запросов из 12, запас на две ошибки при рабочем поиске (таблица эмбеддингов на тех же запросах дает около 0.6). Порог доли внимания на антецедент не ниже 0.2. Пороги считаются по быстрому режиму, потому что CI запускает именно его.

`data/lab03/thresholds.json`: `val_loss_drop` это минимальное падение `val_loss` от шага 0 до последнего шага в режиме `--fast` (200 шагов). В эталонном прогоне падение около 1.5, порог 1.0. Остальное в лабораторной 3 пересчитывается из артефактов без порогов. Обязательных артефактов четыре: `tiny_config.json`, `train_curve.csv`, `samples.json`, `generation.json`; артефакты бонусов (`eval.json`, `greedy_check.json`, `speed.csv`) проверяются, только если они есть, иначе тесты по ним пропускаются. Проверка `greedy_check.json` загружает `Qwen3-0.6B-Base` и повторяет жадную генерацию через `model.generate`.

## Заочное отделение

`test_pt01.py` и `test_pt02.py` устроены так же, работы лежат в `pt01/` и `pt02/`.

`data/pt01/top20.json`: двадцать самых частых слов «Войны и мира» по регулярному выражению из задания, из эталонного прогона 30 октября 2026 года; тест требует совпадения не меньше чем по 15 словам, запас на другой разбор дефисов и «ё». Остальное в первой работе пересчитывается из артефактов без порогов: перплексии конечны и при α = 0.01 ниже, чем при α = 1; связное предложение правдоподобнее перемешанного; слияния BPE воспроизводят разбиения из `examples`.

`data/pt02/thresholds.json`: тот же `val_loss_drop`, что у лабораторной 3, порог 1.0 при падении около 1.5 в быстром режиме. Обязательных артефактов пять: четыре как в лабораторной 3 плюс `eval.json` с точками `bigram` и `tiny`; точка `qwen` и артефакты бонусов проверяются, только если они есть.
