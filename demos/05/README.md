# Демонстрации к лекции 5

Один ноутбук, запускается сверху вниз. Чат-версия `Qwen3-0.6B` и энкодер `multilingual-e5-small` скачиваются с Hugging Face при первом запуске. Корпус это снимок материалов курса из `assignments/05/data/corpus.json`; если файла рядом нет, ноутбук скачает его сам. Тексты всех шагов сохраняются в `fallback/`.

- `demo_rag.ipynb`. Живое демо лекции: вопрос по материалам курса. Тезис: модель во всех шагах одна и та же, а ответ системы определяется тем, что код положил в контекст до вызова и что проверил после. Пять шагов: вопрос без поиска; пять ближайших фрагментов с косинусами; тот же вопрос с фрагментами в промпте; вопрос, ответа на который в материалах нет; проверка двух ответов, сначала вопросом к самой модели, потом повторным вопросом по одному фрагменту с решением в коде.

- `record_steps.py`. Запись для рубрики «Вскрытие», на лекции вживую не запускается: на `Qwen3-4B` идет около сорока минут. Одна и та же серия из 12 вопросов задается модели одним длинным диалогом, где требования названы один раз в начале и модель сама вызывает инструмент `search`, и по одному вопросу в новом контексте. Серий восемь. Считается, на каких шагах модель вызвала поиск и выдержала формат, и что стало с долей выдуманных ответов. Результат в `fallback/06_steps*.csv`, `.md` и `.png`; с флагом `--replot` таблицы и график перестраиваются по готовому csv.

Вопросы задаются переменными `DEMO_QUESTION` и `DEMO_UNANSWERABLE`. Для первого нужен вопрос, на который модель без поиска отвечает неверно, а с фрагментами верно; для второго вопрос по теме курса, ответа на который в материалах нет.

Фолбэк: `01_no_search.md`, `02_search.md`, `03_with_fragments.md`, `04_no_answer.md`, `05_check.md`.
