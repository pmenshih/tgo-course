# Демонстрации к лекции 1

Три ноутбука, каждый запускается сам по себе, сверху вниз. Модели скачиваются с Hugging Face при первом запуске, картинки и тексты сохраняются в `fallback/`.

- `demo_a_likelihood.ipynb`. Правдоподобие руками: кривая $L(p)$ для монетки при 10, 100 и 1000 бросках. На лекции живьем не показывается, из него взята картинка на слайде «Правдоподобие». Полезен, если хочется покрутить число бросков и увидеть, как сжимается пик.
- `demo_b_next_token.ipynb`. Живое демо лекции: распределение следующего токена у `Qwen3-0.6B-Base`, температура и пять продолжений одного промпта, правдоподобие связного и перемешанного предложения. Бонус лабораторной 1 использует его для сравнения со своей моделью на счетчиках.
- `demo_c_hallucination.ipynb`. Рубрика «Вскрытие»: вопрос про несуществующую функцию к чат-версии `Qwen3-0.6B`, пять кандидатов по три прогона и ячейка для живого запуска.

Модели маленькие. Первые два ноутбука на CPU отрабатывают за минуты; полный прогон «Вскрытия», пятнадцать ответов по тысяче токенов, на CPU займет заметно дольше, для лекции достаточно одной живой ячейки в конце.
