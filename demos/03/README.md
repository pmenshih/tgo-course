# Демонстрации к лекции 3

Один ноутбук, запускается сверху вниз. Модели `Qwen3-0.6B-Base` и чат-версия `Qwen3-0.6B` скачиваются с Hugging Face при первом запуске, картинки и тексты сохраняются в `fallback/`.

- `demo_generation.ipynb`. Живое демо лекции: что происходит внутри генерации. Четыре шага: лосс на одном предложении (какую вероятность модель дала каждому настоящему токену); один forward pass руками, логиты, softmax, десятка кандидатов и выбор, три шага подряд; температура на одних и тех же логитах, жадная генерация уходит в цикл, top-p отрезает хвост адаптивно; Base против Instruct на одном вопросе.

Своя функция генерации в ноутбуке та же, что требуется в лабораторной 3, только без top-k и без замера скорости; ноутбук можно использовать как подсказку по API, но не как готовое решение: в нем нет ни маленькой модели, ни трех точек на одном тексте, ни проверки на совпадение с `model.generate`.

На CPU все шаги вместе занимают несколько минут, самый долгий это загрузка второй модели в шаге 3. Фолбэк: `00_token_loss.png`, `01_next_token.png`, `02_generation.txt`, `03_nucleus_size.png`, `04_base_vs_instruct.txt`.
